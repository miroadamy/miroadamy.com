# miroadamy.com

My personal blog - source code. 

The site is generated by Hugo and static HTML is then copied to https://github.com/miroadamy/miroadamy.github.io 
(which is a submodule of this one under `./public`)

Hosting (since 2026-10-03): www.miroadamy.com is served by **Cloudflare Pages**, which deploys automatically
from every push to `miroadamy.github.io` (branch `master`, no build step). GitHub Pages stays enabled on that
repo as the rollback: to revert, point the `www` CNAME in Cloudflare DNS back to `miroadamy.github.io`.
Verified 2026-10-04: a plain `./github-publish.sh` run reached www by itself, and GitHub Pages received the
same build, so the rollback target is always current.
Nothing in this repo or in `github-publish.sh` changes for either direction.

Using the Blowfish theme of Hugo - https://github.com/nunocoracao/blowfish (v3.8.0; the former Even theme stays under `themes/even`, unused)
